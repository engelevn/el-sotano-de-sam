# El Sótano de Sam — Stock en Línea

Inventory management system for a real vintage and imported clothing store based in Tuluá, Colombia.

## About
I built this app for an actual store that sells vintage and imported clothing. The owner needed a way to manage stock without spreadsheets, so I made this — a simple web system where you can add, edit, delete and search products in real time.

This was my final project for the ADSO program at SENA.

## Tech Stack
- Python + Flask
- SQLite
- HTML, CSS, JavaScript

## Features
- Login and authentication
- Full product CRUD
- Real-time search
- COP and USD currency toggle
- Light and dark mode
- SAMBOT chatbot
- Toast notifications

## Run it locally

```bash
git clone https://github.com/engelevn/el-sotano-de-sam.git
cd el-sotano-de-sam/el-sotano-de-sam
pip install -r requirements.txt
py app.py
```
